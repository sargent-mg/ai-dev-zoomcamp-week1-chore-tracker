# Household Chore Tracker — v1 Scope

## Overview
A lean, low-friction tool for a family with kids to manage daily household chores, focused on **reminders/consistency** rather than fairness tracking or motivation/rewards.

## Users
- **Household type**: Family with kids
- **Size**: 3-4 people (e.g., 2 parents + 1-2 kids)
- **Login**: No login — shared household link, each person picks their name to identify themselves

## Chores
- **Recurrence**: Daily only (no weekly or one-off chores in v1)
- **Assignment**: Fixed schedule — each person is permanently assigned the same chore(s) (e.g., Mom = dishes, every day)

## Visibility
- One shared list — everyone sees all chores for all household members (no personal-only view)

## Completion Tracking
- **Self check-off**: Honor system, person marks their own chore as done
- No photo proof required
- No parent verification/approval step

## Missed Chores
- No automatic escalation or notifications
- Missed chores are simply logged as "missed" in history

## Notifications
- In-app only — no push notifications, no physical/wall display

## Platform
- Responsive web app, mobile-friendly
- No app install required

## Explicitly Out of Scope (v1)
- Chore rotation between people
- Points/rewards/allowance/gamification
- Push notifications
- Photo proof or parent approval workflows
- Full authentication (email/password accounts)
- Escalation or notify-others logic for missed chores

## Future Considerations
- Rotation could be added later if fixed assignment feels unfair
- Points/rewards could be layered in if motivation becomes an issue
- Push notifications could be added if in-app reminders aren't effective enough
